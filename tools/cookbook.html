Cookbook

Your recipes, kept in your own Dropbox. Send it a link and it files the recipe.

Cookbook only sees its own folder in your Dropbox (Apps/<your app name>/). Nothing is stored on this website.

First-time setup (about five minutes, once)
  1. Go to dropbox.com/developers/apps and choose Create app: Scoped access, then App folder. Name it, for example Enrico Cookbook.
  2. In Permissions, tick files.metadata.read, files.content.read and files.content.write, then Submit.
  3. In Settings → OAuth 2 → Redirect URIs, add exactly:
  4. Copy the App key (not the secret) into the box below, then press Connect Dropbox.

The app key is a public identifier. Never paste an app secret or token here.

      Or use the button on the recipe page

      Some sites won't let Dropbox fetch them. For those, save this button as a bookmark, then tap it while you're on the recipe:

      + Cookbook

      How to add the button
      1. Computer: drag + Cookbook onto your bookmarks bar.
      2. iPhone or iPad: bookmark any page, then edit that bookmark: name it + Cookbook and replace its address with the button's. To copy the address, press and hold + Cookbook and choose Copy Link.
      3. Android (Chrome): same as iPhone, then type the bookmark's name into the address bar on a recipe page and pick it from the list.

      Books

      Put cookbook PDFs in the books folder inside Cookbook's folder in your Dropbox (Apps/<your app name>/books). They stay private.
