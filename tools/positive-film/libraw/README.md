# LibRaw-Wasm 1.6.0 (vendored)

Unmodified build files from the npm package `libraw-wasm` 1.6.0 (https://github.com/ybouane/LibRaw-Wasm, ISC licence), used by `tools/positive-film/index.html` to decode RAW files in the browser.

LibRaw itself is licensed under LGPL 2.1 or CDDL 1.0 (https://www.libraw.org/). The decoder needs cross-origin isolation, which `tools/positive-film/coi-serviceworker.js` (coi-serviceworker 0.1.7, MIT) provides on GitHub Pages.
