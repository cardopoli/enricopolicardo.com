WordPress plugins / ReThinkable Festival

Three plugins,
three menus.

The ReThinkable Festival website runs on three small WordPress plugins. Each one has its own menu in the WordPress sidebar, and each can be updated or switched off without touching the others.

Released 20 November 2026 - built for ReThinkable, readable source in every ZIP

Test before you trust. The packages pass PHP syntax checks, but they haven't been tested end to end on a staging copy or the live site yet. The AI Connection plugin hasn't had an independent security review. Back up first, upgrade one plugin at a time.

The plugins

Homepage & Design

Editorial Kit 1.1.0

Edit the festival homepage in Italian, Slovenian and English - copy, images and video - through simple fields, with optional styles. The new homepage stays hidden until an administrator switches it on.

Download ZIP

Partners & Supporters

Partners Manager 1.2.1

Partners and supporters for each festival edition: names, links, logos, order and visibility. Copy an edition to start the next one; past editions keep their own credits. Includes the nine RT.5 logos.

Install or upgrade

  1. Make a backup of the site and database that you know restores. Use a staging copy if you can.
  2. In WordPress, go to Plugins → Add New → Upload Plugin and choose one ZIP. One plugin at a time.
  3. If you're upgrading, choose Replace current with uploaded. Don't delete or uninstall first - your settings, partner editions and AI connections stay as they are.
  4. Check that the three menus appear in the sidebar: Homepage & Design, Partners & Supporters and AI Connection.
  5. Check the homepage in IT, SL and EN, on desktop and phone, plus the footer logos and an event booking.
  6. Keep the AI Connection read-only unless you need more, and never copy its sign-in tokens anywhere public.

To roll back, upload the previous ZIP the same way. Don't delete the plugin.
