Want it live in Photoshop, with the type still editable? Download Shredder for Photoshop - then File > Scripts > Browse… and pick the file. Select a type layer first. Tick "vector copy" for a shape layer you can paste into Illustrator.
Prefer one-click layer styles? Download Shredder Styles - run it once and eight styles appear in Window > Styles.

Runs in your browser - nothing is uploaded. Transparent PNGs drop straight into Photoshop, InDesign or Illustrator. The SVG is the same result traced into vector shapes, one per ink colour. Drop an image anywhere on the page to shred it.
