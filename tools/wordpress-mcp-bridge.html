An open-source, self-hosted Model Context Protocol bridge for WordPress. Give a compatible AI assistant controlled access to manage content, inspect your website and propose changes without handing it your WordPress password.

Version 0.6.2 public beta - GPL-2.0-or-later - self-hosted WordPress

Download free WordPress plugin (ZIP) Documentation and source information

Beta software. The package has passed local PHP syntax checks, but has not been independently security audited or tested end-to-end with every client. Test on staging before using it on a live WordPress site. Connections and changes require WordPress administrator authorisation.

Works with compatible MCP clients

ChatGPT
Previously connected using the WordPress bridge's remote MCP and OAuth endpoint. Retest after upgrading to this build.

Claude / Claude Desktop
Intended support using custom remote connector and automatic OAuth client registration (DCR). Add claude.ai to the permitted callback domains. End-to-end validation pending.

Other MCP-compatible clients
Use a remote Streamable HTTP client supporting OAuth and dynamic registration. Some desktops require a loopback callback or intermediary. Check each client's own documentation.

Not every AI platform
MCP is a protocol, not a promise that all assistants support remote servers or the same login flow.

Start with read-only access

  1. Back up your WordPress website and database. Test restoration on staging.
  2. In WordPress open Plugins → Add New → Upload Plugin and select the downloaded ZIP.
  3. Go to Settings → Universal MCP Bridge and copy the MCP server URL shown there.
  4. Enable connections while leaving write, maintenance and code-edit tools off.
  5. In your AI client, add a custom remote MCP server with OAuth DCR. Set exact callback domains, then log in as a WordPress administrator and approve access.
  6. Test basic read tools before enabling controlled writes.

A client may impose its own account requirements, rate limits or costs. This plugin does not bypass them.
