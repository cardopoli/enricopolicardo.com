WordPress,
meet your AI.

A free, open-source plugin that turns your WordPress site into an MCP server. Claude - or any assistant that supports remote MCP - can read your pages, check the site's health and draft changes. Anything that writes waits for your approval, and your WordPress password never leaves WordPress.

Version 0.6.2 public beta - GPL-2.0-or-later - runs on your own WordPress

Download the plugin (ZIP) Docs and source

This is a beta. It passes PHP syntax checks, but it hasn't had an independent security audit, and it hasn't been tested end to end with every client. Try it on a staging copy first. Every connection, and every change, needs a WordPress administrator's approval.

What it does

Reads
Pages, posts, media, plugins, site health and backup status. This is all it can do until you switch writing on.

Writes, if you let it
Drafts, text and SEO edits, maintenance requests and small theme code fixes. Each one is off by default, and each change is approved inside WordPress. Code edits keep a rollback copy.

Connects to Claude
Add it as a custom connector using your site's MCP address and choose automatic sign-in registration. Add claude.ai to the plugin's allowed callback domains first. Full end-to-end testing with Claude is still to come.

And other MCP clients
Any client that supports remote MCP over HTTPS, with OAuth and dynamic client registration. Add its callback domain to the allowed list. Not every assistant supports remote MCP yet - check yours first.

Set it up, read-only first

  1. Back up the site and database, and check that the backup actually restores.
  2. In WordPress, go to Plugins → Add New → Upload Plugin and choose the ZIP.
  3. Open Settings → Universal MCP Bridge, switch connections on and copy the MCP address. Leave writing, maintenance and code edits off for now.
  4. Add claude.ai - or your client's callback domain - to the allowed domains.
  5. In your AI client, add a custom connector with that address. Sign in as a WordPress administrator and approve access.
  6. Try the read tools. Switch writing on only when you're happy with what you see.

Your AI client may have its own plan requirements, limits or costs. The plugin doesn't change those.
