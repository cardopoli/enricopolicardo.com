Tables and fenced code blocks are supported. Markdown files import as new pieces without changing existing work. Markdown exports preserve the draft exactly; TXT exports contain the readable text. Hugo YAML or TOML front matter stays in the file and is omitted from the preview.

Saving, sharing and privacy

Your writing stays in this browser unless you export or share it. The desk works offline and has no accounts, analytics or external scripts. Browser storage can be cleared, so keep a downloaded backup.

Text (.txt) opens almost anywhere. Markdown (.md) keeps headings. Backup (.json) preserves every piece, source answer, saved prompt and version, ready to import.

Notes: copy your draft and paste it into Apple Notes or another notes app. Where your browser supports system sharing, “Share text” opens the available share options. Choose Notes if your device offers it. A local webpage cannot silently add a note to Apple Notes.

The timer uses elapsed time while the page is running. If a device sleeps, it catches up when the page returns. It cannot guarantee a background alarm after the browser closes.

A simple way to use the desk

  1. Name the piece and say what it is for.
  2. Pick a prompt, change it, or write without one.
  3. Highlight useful words and press “Keep selection”. Save answers when you want to start a fresh one.
  4. Order your collected lines. Add them to the draft and edit in your own words.
  5. Save a version before a large change. Export the draft or download a full backup.

The timer is optional. Breaks wait for you to start them. Nothing rewrites your text automatically.

Shortcuts: ⌘/Ctrl+S saves locally. ⌘/Ctrl+Enter keeps a selection in rough writing. Escape leaves quiet view.
